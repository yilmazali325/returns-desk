Q1 · Architecture · 2 AI agents, 7 code parts

Two AI agents do the work; code keeps it safe

✓ Selected: two AI agents with separate jobs. Why: the agent that reads the customer can't change money or stock, and the agent that can never reads the customer's words. Code can block, read or replay, but never proposes or carries out anything itself.

All on one laptop, internet off: both AI agents run on Qwen3.5-4B (4-bit) with llama.cpp on the Apple M5 Pro graphics chip

AI agent: an AI model that decides the next step and uses tools, not just writes text · Tool: one action an agent can ask for, like "create proposal" · Proposal: the offer shown to the customer before anything changes · Store rules: delivered, unopened, not final sale, within 30 days · SQLite: a small database kept in one file on the laptop · Timeout: an answer that never arrives · Block, read, replay: the only three things code may do to an agent's choice

Q5 · Model and engine

A small open model, on one laptop, internet off

✓ Selected: Qwen3.5-4B in 4-bit, run by llama.cpp on an Apple M5 Pro laptop. Why: about 5 seconds per case, reliable at filling the agents' tool forms, and no customer data ever leaves the machine.
ChoiceSelectedIn plain wordsWhy, and the tradeoffEvidence
AI modelQwen3.5-4BAn open AI model with 4 billion learned numbersFast and reliable at tool calls here; a bigger model may read odd wording better, but slowerNot compared
Model size4-bit (B: 8-bit)Q4_K_M · B: Q8_0Each learned number stored in fewer bits22% faster and 1.6 GiB less graphics memory, same quality✓ Measured
Tool callsA fixed answer form (B: the model's own format)The model can only write answers in the exact shape our tools expect36% faster and fewer broken answers, same quality✓ Measured
Enginellama.cppFree software that runs the model on the laptop's graphics chipWorks offline, enforces the answer form, reports its own speed; other engines not testedNot compared
HardwareApple M5 Pro, 24 gigabytesOne laptop: 15 CPU cores, 16-core GPU, shared memoryNo hardware purchase; plugged in, one request at a timeDisclosed

The main tradeoff: speed and privacy over a bigger model's language range. Typos and Spanish product words make the desk ask instead of act (Q9).

Open model: an AI model anyone can download and run · Qwen3.5-4B: the open model used, 4 billion learned numbers · 4-bit / 8-bit (Q4_K_M / Q8_0): how precisely each number is stored; fewer bits = smaller and faster · B: the baseline version · Engine (llama.cpp): the program that runs the AI model · Fixed answer form (JSON schema): the shape every answer must fit · GPU: the graphics chip, which does AI maths in parallel · CPU: the general-purpose processor · GiB: 2^30 bytes

Q7 · How it was tested

Every case scored against the right answer

364 test cases

  • Public: 6, run 3 times
  • Variants: 241 reworded
  • Red-team: 57 tricky
  • Blind: 60, written without the code

Success means all of

  • Every decision right
  • Exact offer: item, size, amount
  • Final money and stock right
  • Zero rule breaks

Fair comparison

  • Same laptop, runs interleaved
  • Fresh model server each run
  • Checker written apart from the desk
  • Baseline run twice for noise

What the blind test caught

"Yes, refund the t-shirt" on a jeans offer refunded the jeans. Only comparing final data caught it. Fixed in two rounds: 56 → 57 → 58 of 60.
